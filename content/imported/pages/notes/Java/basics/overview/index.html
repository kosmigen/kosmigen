Java 核心知识¶

核心部分介绍编写日常 Java 程序需要掌握的语法和标准库。建议先完成基本语法，再依次学习对象、容器、异常与文件操作。

本部分内容¶

专题 需要掌握的问题
基本语法 如何声明变量、选择类型、使用运算符和定义方法？
流程控制 如何根据条件选择分支，重复执行一段代码？
面向对象 如何通过类、接口和对象组织状态与行为？
字符串与数组 如何处理文本、保存和遍历固定数量的数据？
集合框架 如何选择列表、集合、映射和队列？
泛型 如何让类和方法适用于多种类型，并保留类型检查？
异常处理 如何表示失败、处理异常和清理资源？
文件与 IO 如何表示路径，读写文本和二进制数据？

如何使用示例¶

完整示例会标明文件名，并给出输出或预期现象。以 Main.java 为例：

javac -encoding UTF-8 Main.java
java Main

代码中的路径、输入和类型可以自行修改。先运行原始示例，再改变一个条件观察结果，例如把合法下标改成越界下标，或把可修改集合换成不可修改集合。

学完之后¶

尝试编写一个命令行学习记录程序：使用对象表示记录，使用集合管理数据，通过异常处理校验输入，最后将记录保存到文件。再进入进阶，学习并发、网络和运行时机制。
