最近在网上看着许多的视频都是使用 AI 完全从零开始制作一个项目，我就在思考这样的方式真的很好吗？还是说只能给人一种做了很多的效果，让人有一种虚假的成就感，但其实效果并不佳。

在软件领域，我认为能建立在成熟的基础之上进行构建最符合最佳实践！

熟知的 github 上拥有丰富的资源，包括各种问题的解决方案，如果我们在将自己的需求思考完整后，先去 github 上寻找最类似的项目，然后进行一定的修改， 肯定比自己从零实现一个项目好的多，并且安全的多。

所以就引出我对 AI 及相关产品开发的最佳工作流的设计：

  1. 思考自己的完整需求
  2. 在 github 上搜索类似项目（每个需求都可以去寻找对应的类似项目）
  3. 对项目进行适配修改
  4. 验证项目是否符合自己的需求

我创建一个项目来进行验证。

背景：我最近在购买基金，所以先让 AI 和我进行讨论，可以设计出什么样的关于基金的项目。
